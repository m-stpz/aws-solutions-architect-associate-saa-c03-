# S3 Storage classes

Amazon S3...

- Standard
  - Infrequent Access
- One Zone: Infrequent Access
- Glacier
  - Instant retrieval
  - Flexible retrieval
  - Deep archive
- Intelligent tiering

- Can move between classes manually or using s3 lifecycle config

> Storage classes are implemented at the OBJECT LEVEL, not the BUCKET LEVEL

- A single S3 bucket can hold objects stored in different storage classes
  - some in S3 standard
  - some in S2 standard-IA
  - some in glacier flexible retrieval
  - etc

- Per-object assignment
  - when object is uploaded, we can specify the storage class via the `x-amz-storage-class` header
  - if no class is specified, then it defaults to s3 standard
- Change storage on existing objects
  - we can change the storage class later

- Despite the storage class being an object-level property, we can manage the storage collectively through **lifecycle rules**
  - transition current versions of objects between storage classes
    - then, we can select the storage class and "days after object creation"

## Durability and Availability

- Durability: very high and same of all storage classes
  - high durability [99.999999999 - 11 9's] of objects across multiple AZ
  - Meaning, if you store 10M objects with s3, expect on average to incur a loss of a single object once every 10k years
  - same for all storage classes

- Availability: differ from class to class
  - how readily available a service is
  - varies depending on storage class
  - ex: s3 standard has 99.99% availability
    - not available 53 min/year

## S3 Standard - General purpose

- 99.99% availabilty
- Used for frequently accessed data
- Low latency and high throughput
- Can sustain 2 concurrent facility failures

- When to use it?
  - big data analytics
  - mobile and gaming applications
  - content distribution

## S3 Infrequent Access [Standard & One Zone]

- Data that is less frequently accessed, but requires rapid access when needed
- Lower cost than s3 standard

- Two types:

1. Standard infrequent access [S3 Standard-IA]

- 99.9% availability
- use cases: disaster recovery, backups

2. One zone infrequent access [S3 One Zone-IA]

- high durability (11 9's) in a single AZ, however, data is lost when AZ is destroyed
- 99.5% availability
- use cases: storing secondary backup copies of on-premise data, or data you can recreate

## S3 Glacier [Instant, Flexible, and Deep Archive Retrievals]

- Low-cost object storage meant for archiving / backup
- Pricing: price per storage + object retrieval cost

- 3 types
  - Glacier instant retrieval
    - millisecond retrieval, great for data access once a quarter
    - minimum storage duration 90 days
  - Glacier flexible retrieval [formerly amazon s3 glacier]
    - expedited [1-5 min], standard [3-5h], bulk [5-12h] - free
    - minimum storage duration 90 days
  - Deep archive: long term storage
    - standard [12h], bulk [48h]
    - minimum storage duration of 180 days

## S3 Intelligent-tiering

- Small monthly monitoring and auto-tiering fee
- Moves objects automatically between access tiers based on usage
- No retrieval charges in S3 intelligent-tiering

| Type                        | automatic/optional | condition                          |
| --------------------------- | ------------------ | ---------------------------------- |
| frequent access tier        | automatic          | default tier                       |
| infrequent access tier      | automatic          | objects not accessed for 30 days   |
| archive instant access tier | automatic          | ... 90 days                        |
| archive access tier         | optional           | configurable from 90 to 700+ days  |
| deep archive access tier    | optional           | configurable from 180 to 700+ days |
