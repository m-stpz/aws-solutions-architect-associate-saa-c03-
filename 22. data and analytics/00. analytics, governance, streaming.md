# AWS Data Analytics, Governance and Streaming

| Service                           | Core purpose and category                                   | Architecture and scaling                                                                                         | Use case                                                                                 | Exam trigger                                                                           |
| --------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Athena                            | serverless interactive SQL query engine                     | scale files directly in S3; pay-per-query model                                                                  | ad-hoc data exploration, querying raw logs in s3                                         | query data directly in s3 using standard SQL without provisioning infra                |
| Redshift                          | fully managed petabyte-scale data warehose [OLAP]           | massinve parallel processing architecture using columnar storage, sort/dist keys, clusters/serverless            | enterprise BI, complex multi-table joins, heavy reporting                                | high-performance analytical data warehouse for complex queries                         |
| OpenSearch                        | distributed search, log analytics, and observability engine | cluster nodes running apache Lucene; handles full-text indexing, fuzzy searches and metrics                      | application search, log analytics, and real-time dashboarding                            | full text-search, kibana dashboards, or real-time log ingestion and aggregation        |
| EMR [Elastic MapReduce]           | big data framework for large-scale data processing          | managed cluster platform running open-source frameworks like spark, hive, haddop, and presto                     | large-scale distributed data processing, machine learning, and custom ETL pipelines      | run open-source big data frameworks [spark/hadoop] on managed clusters                 |
| QuickSight                        | serverless BI visualization                                 | cloud-powered, auto-scaling reporting layer featuring SPICE [super-fast, parallel, in-memory calculation engine] | sharing interactive business dashboards, reports, and embedded analytics with users      | serverless cloud-native business intelligence and visualization tool                   |
| Glue                              | serverless ETL, metadata catalog, and crawlers              | serverless apache spark execution engine + centralized metadata repo [data catalog]                              | automating data discover, cleaning, transforming, and loading data into lakes/warehouses | serverless ETL service/automated schema discovery via glue crawlers                    |
| Lake Formation                    | centralized data lake governance and security               | adds a db-style permission layer and fine-grained access control on top of s3                                    | enforcing row, column, and cell-level security for multi-tenant data lakes               | fine-grained access control [row/column/cell level] and cnetralized data lake security |
| Managed service for Apache Flink  | real-time stateful stream processing                        | fully managed apache flink clusters supporting Java, SQL, Scale, Python with windowing capabilities              | real-time analytics, anomaly detection, live metrics, and sliding-window aggregations    | low-latency, stateful processing of streaming data streams using windowing/SQL         |
| MSK [Managed Streaming for Kakfa] | fully managed apache kafka messaging and event streaming    | highly available, clustered kafka brokers managed by AWS for high-throughput pub/sub pipelines                   | real-time data pipelines, event-driven microservices messaging, and stream ingestion     | fully managed apache kafka service for high-throughput streaming ingestion             |
