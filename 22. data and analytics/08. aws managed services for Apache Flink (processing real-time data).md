# AWS Managed Service for Apache Flink

- Previously called Kinesis Data Analytics for Apache Flink
- Flink [Java, Scale or SQL] is a framework for processing data streams
  - allows processing and analyzing streaming data in real time
- continuous, real-time stream processing

```
Kinesis data streams -----|
                          |----> Amazon managed service for apache flink
Amazon MSK ---------------|
[apache Kafka]
```

- Run any Apache Flink application on a managed cluster on AWS
  - provisioned compute resources, parallel computatio, automatic scaling
  - application backups [implemented as checkpoints and snapshots]
  - use any apache flink programming features to transform data
- Flink doesn't read from Amazon Data Firehose

## Main use cases

- Real-time analytics and dashboards
  - streaming clickstreams, tracking metrics, or computing live metrics
- Fraud detection and dynamic rules engines
  - analyzing user behavior behavior sequences across sliding time windows to spot anomalies or fraudulent credit card swipes instantly
- Real-time ETL / data enrichment
  - joining a fast-moving stream of IoT sensor logs with reference metadata stored in a db before wrigin the clean output to a data lake
