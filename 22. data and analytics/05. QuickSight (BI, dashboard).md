# QuickSight - BI/Dashboards

- Serverless machine learning-powered BI service to create interactive dashboards
- Fast, automatically scalable, embeddable, with per-session pricing

- Use cases:
  - business analytics
  - building visualizations
  - perform ad-hoc analysis
  - get business insights using data

- Integrated with:
  - RDS
  - Aurora
  - Athena
  - Redshift
  - S3

- In-memory computation using SPICE engine if data is imported into QuickSight
- Enterprise edition: possibility to setup Column-Level security [CLS]
  - allow visualization if users have the necessary permissions

## Dashboard and Analysis

- Define users [standard versions] and groups [enterprise version]
  - these users and groups only exist within QuickSight, not IAM
- Dashboard
  - read-only snapshot of an analysis that you can share
  - preserves the confi of the analysis [filtering, params, controls, sort]

- You can share the analysis or the dashboard with users or groups
  - to share a dashboard, you must first publish it
  - users who see the dashboard can also see the underlying data
