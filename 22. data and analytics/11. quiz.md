# Quiz - Data and Analytics

1. You would like to have a database that is efficient at performing analytical queries on large sets of columnar data. You would like to connect to this Data Warehouse using a reporting and dashboard tool such as Amazon QuickSight. Which AWS technology do you recommend?

- Redshift
  - data warehouse and analytical queries
  - columnar data
  - quicksight integration

- why not?
  - RDS
    - traditional transactional OLTP relational db
    - optimized for row-based CRUD operations, not massive analytical data warehousing
  - S3
    - flat object storage, not a dedicated columnar data warehouse
  - Neptune
    - graph db

2. You have a lot of log files stored in an S3 bucket that you want to perform a quick analysis, if possible Serverless, to filter the logs and find users that attempted to make an unauthorized action. Which AWS service allows you to do so?

- Athena
  - logs files stored in a s3 bucket: Athena queries data directly from S3
  - serverless: only pay for the amount of data scanned
  - write SQL queries to search, filter and inspect logs

- why not?
  - dynamodb
    - nosql transactional db optimized for key-value lookups, not ad-hoc serverless SQL analysis over raw files in s3
  - redshift
    - analytical data warehouse
    - requires provisioning and managing clusters, making it less lightweight
    - more overhead compared with Athena

3. As a Solutions Architect, you have been instructed you to prepare a disaster recovery plan for a Redshift cluster. What should you do?

- Enable automated snapshots, then config redshift cluster to automatically copy snapshots to another AWS region

4. Which feature in Redshift forces all COPY and UNLOAD traffic moving between your cluster and data repositories through your VPCs?

- Enhanced VPC routing
  - COPY: loading data into redshift
  - UNLOAD: exporting data out of redshift
  - by default these operations run through the public internet, and not your private VPC infra
  - how enhanced VPC routing works
    - when you enable it, Redshift forces ALL COPY and UNLOAD to route through your VPC

6. An AWS service allows you to create, run, and monitor ETL (extract, transform, and load) jobs in a few clicks.

- AWS Glue

7. A company is using AWS to host its public websites and internal applications. Those different websites and applications generate a lot of logs and traces. There is a requirement to centrally store those logs and efficiently search and analyze those logs in real-time for detection of any errors and if there is a threat. Which AWS service can help them efficiently store and analyze logs?

- OpenSearch
  - centrally store those logs and efficiently search and analyze those logs in real-time
    - open search is a distributed search and analytics engine
    - built for full-text searching, LOG ANALYTICS, METRICS collection, and real-time visualization
  - detection of any errors and if there's a threat
    - widely used as the core engine for SIEM [security information and event management]

8. ……………………….. makes it easy and cost-effective for data engineers and analysts to run applications built using open source big data frameworks such as Apache Spark, Hive, or Presto without having to operate or manage clusters.

- Amazon EMR [Elastic MapReduce]

9. An e-commerce company has all its historical data such as orders, customers, revenues, and sales for the previous years hosted on a Redshift cluster. The DevOps team is assigned to find an AWS service that can help define those dashboards and have native integration with Redshift. Which AWS service is best suited?

10. Which AWS Glue feature allows you to save and track the data that has already been processed during a previous run of a Glue ETL job?

- Glue job bookmarks
  - saves the state of previous job runs
  - trackes which files, tables or partitions have already been processed

11. You are a DevOps engineer in a machine learning company which 3 TB of JSON files stored in an S3 bucket. There’s a requirement to do some analytics on those files using Amazon Athena and you have been tasked to find a way to convert those files’ format from JSON to Apache Parquet. Which AWS service is best suited?

- AWS Glue
  - conver those files from JSON to apache parquet
  - glue: ETL that can read input files [ex: json] and conver, compress and write them into optimized columnar formats like parquet
  - converting JSON to parquet drastically reduces storage size and speeds up query performance for downstream tools like Athena

What is the best option you recommend to migrate Apache Kafka?

14. Which AWS service is most appropriate when you want to perform real-time analytics on streams of data?

- Kinesis data analytics
  - renamed to Amazon Managed Service for Apache Flink
  - real-time analytics on streams of data: buit for continuously process, query, and analyze high-throughput streaming data in real time
  - uses SQL, Java, Scala, Python

- why not?
  - SQS
    - designed for decoupling microservices and buffer messages, not to perform real-time data analytics
  - SNS
    - pub/sub notification service for broadcasting alerts, emails, or mobile push notifications to subs, not for stream computation
  - Firehose
    - delivery service to capture, batch, and load streaming data into destinations
    - destinations: s3, redshift, or opensearch
    - ingestion and loading pipe, not an analytical query engine
