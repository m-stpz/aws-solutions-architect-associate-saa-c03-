# MQ

- SQS, SNS are "cloud-native" services, they are proprietary protocols from AWS
- Traditional applications running from on-prem may use open protocols
  - MQTT, AMQP, STOMP, Openwire, WSS
- When migrating to the cloud, instead of reenginering the application to use SQS and SNS, we can use MQ
- MQ is a managed message broker service for
  - RabbitMQ
  - ActiveMQ
- MQ
  - doesn't scale as much as SQS/SNS
  - runs on servers, can run multi-az with failover
  - has both queue [SQS] and topic [SNS] features

## High availability

```
            region [us-east-1]

            | active AZ1 [us-east-1a] |
Client ---->| MQ Broker               |<------
    |                                          |--> EFS [storage]
failover -->| standby AZ2 [us-east-1b]|<------
            | MQ Broker               |
```
