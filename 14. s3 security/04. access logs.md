# Access Log

- For auditing purposes, you can log all access to S3 buckets
- Any requests made to s3, from any account, authorized or denied, will be logged into another S3 bucket
- Data is analyzed using data analysis tools
- Target logging bucket must in the same AWS region

```
                        [target bucket]                         [monitoring bucket]
user ---[requests]---> | my-bucket | ---[logs all requests]---> | logging-bucket |
```

**⚠️ Important**:

- do not set the TARGET bucket of monitoring the same as the MONITORING bucket
  - otherwise, you'll create a logging loop and the bucket will grow exponentially

## Hands on

- Create the monitoring bucket
  - meaning, the bucket the logs will be added TO
- Select the target monitoring bucket
  - meaning, the bucket you'd like to have the logs FROM
- Amazon s3 / buckets / <target-monitoring-bucket> / edit server access loggin
  - enable
  - select the destination
  - select your monitoring bucket
