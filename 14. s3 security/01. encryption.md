# S3 Encryption

We can encrypt objects in s3 buckets using 1 of 4 methods

## Server-side encryption[SSE]

Comes in 3 types

1. SSE-S3: uses amazon s3-managed keys [enabled by default]

- encrypts s3 objects using keys handled, managed, and owned by AWS
  - we don't have access to this key

- encryption type is AES-256
- must set header `"x-amz-server-side-encryption":"AES256"`
- enabled by default for new buckets and new objects

```
        http[s] + header  | amazon s3                                   |
user -----> upload ------>| object  ----- [encryption] ----> s3 bucket  |
                          | + s3 owned key                              |
```

2. SSE-KMS: uses KMS keys stored in AWS KMS

- leverages AWS Key Management Service [AWS KMS] to manage encryption keys
- advantages:
  - user control + audit key usage using CloudTrail
- must set header `"x-amz-server-side-encryption:"aws:kms"`

```
        http[s] + header  | amazon s3                                   |
user -----> upload ------>| object  ----- [encryption] ----> s3 bucket  |
                          | + AWS KMS [kms key]                         |
```

3. SSE-C: uses Customer-provided keys

- when you want to manage your own encryption keys

## 4. Client-side encryption

The 4th type is not server-side, but client
