# MFA Delete

- MFA [Multi-factor authentication]: force users to generate a code on a device before doing important operations
  - ex: Authy
- On S3, MFA:
  - will be required to:
    - permanently delete an object version
    - suspend versioning on the bucket
  - won't be required to:
    - enable versioning
    - list deleted versions

## Hands on

- Create bucket and go to it
- Amazon S3 / <bucket-name> / Edit Bucket Versioning
  - enable MFA delete
  - in the time of the recording, you couldn't do this through the UI/Console, you need to enable this through the CLI

- For it, you need to enable MFA on the ROOT account
