# Access Point

- Access point simplifies security management for S3 bucket
- Each access point has:
  - its own DNS name [Internet origin / VPC origin]
  - an access point policy: manage security at scale
    - similar to bucket policy

```
                policy grants R/W to /finance prefix
users [finance] -----> [finance access point] ------ | s3 bucket --> this way, the bucket can retain a simple bucket policy
                                                     |  /finance/...
                policy grants R/W to /sales prefix   |
users [sales] -------> [sales access point]--------- |  /sales/
                                                     |
                policy grants R to entire bucket     |
users [analytics] ---> [analytics access point]----- |
```

## VPC Origin

- We can define the access point to be accessible only from within the VPC
