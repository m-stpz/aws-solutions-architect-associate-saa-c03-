# S3 Cors

- CORS: Cross-Origin Resource Sharing
  - origin: protocol + domain + port
    - ex: `https://example.com`
      - implied port: 443 https / 80 http
- It's a web browser mechanism to allow/reject requests to other origins while vising the main origin
  - same origin: `http://example.com/app1` and `http://example.com/app2`
  - different origin: http://example.com` and `http://other.example.com`
- Request won't be fulfilled unless the other origin ALLOWS for the requests, using the **CORS Headers** [ex: `Access-Control-Allow-Origin`]

```
[ Web Server (Origin) ]                 [ Web Browser ]                 [ Web Server (Cross-Origin) ]
https://www.example.com                                                 https://www.other.com
         │                                     │                                  │
         │◄───────── HTTPS Request ───────────►│                                  │
         │                                     │                                  │
         │                                     │── OPTIONS / ────────────────────►│
         │                                     │   Host: www.other.com            │
         │                                     │   Origin: https://www.example.com│
         │                                     │   (Preflight Request)            │
         │                                     │                                  │
         │                                     │◄─ Access-Control-Allow-Origin:   │
         │                                     │   https://www.example.com        │
         │                                     │   Access-Control-Allow-Methods:  │
         │                                     │   GET, PUT, DELETE               │
         │                                     │   (Preflight Response)           │
         │                                     │                                  │
         │                                     │── GET / ────────────────────────►│
         │                                     │   Host: www.other.com            │
         │                                     │   Origin: https://www.example.com│
         │                                     │                                  │
         │                                     │   [ CORS Headers received already│
         │                                     │     by the Origin. The Web       │
         │                                     │     Browser can make requests ]
```
