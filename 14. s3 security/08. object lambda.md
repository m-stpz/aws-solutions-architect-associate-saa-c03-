# S3 Object Lambda

- Use AWS lambda functions to change the object before it's retrived by the caller application
- Only one S3 bucket is needed, on top of which we create:
  - S3 access point
  - s3 object lambda access point

- Use cases
  - redacting/cutting out some info for analytics and non-prod envs
    - ex: removing sensible informationg
  - converting data from one format to the other
    - ex: converting XML to json
  - resizing and watermarking images on the fly

```
s3 bucket -------------------[origin obj] ----> e-commerce application
    |
[supporting s3
access point]
    |
    --- [redacting lambda func] ---> [s3 object lambda ----> [redacted object] ---> analytics application
    |                                     access point]
    ----[enriching lambda func] ---> [s3 object lambda ----> [enriched object] ---> marking application
                 |                     access point]
                 |
        [customer loyalty db]

```
