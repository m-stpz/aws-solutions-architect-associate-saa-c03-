# Pre-Signed URL

- Generate pre-signed URls using the S3 console, AWS CLI or SDK
  - pre-signed = pre-authorized
- URL expiration
  - S3 console: 1 min to 720 min [12 hours]
  - AWS CLI: configure expiration with `--expires-in` parameter in seconds [default 3600 secs, max. 604800 secs ~ 168h]
- Users given a pre-signed URL INHERIT the permissions of the user that GENERATED the URL for GET / PUT

```
  ---------------------- [3. provide the URL]---------------------------------------------------
 |                                                                                              |
owner --- [1. generate pre-signed URL] ---> | s3 bucket | <-- [4. user pre-signed URL] --- requesting user
      <-- [2. return the URL] ------------- | [private] | ----[5. return the file] ------->
```

- Use cases:
  - give someone temporary GET access to a file in your private s3 bucket
  - allow only logged-in users to download a premium video from s3 bucket
  - allow an ever-changing list of users to download files by generating URLs dynamically
  - allow temporarily a user to upload a file to a precise location of your S3 bucket

> It's like sharing a file/folder with a user on Google Drive
