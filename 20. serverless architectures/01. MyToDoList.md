# Serverless Architecture 1: MyToDoList

- Mobile application with:
  - expose Rest API with HTTPS: API gateway
  - serverless architecture: lambda

- Users should be able to:
  - directly interact with their own folder in s3: cognito identity pool
  - authenticate through managed serverless service: cognito user pool
  - write and read to-dos, but mostly read them: maybe DAX for caching?
  - db should scale, have high read throughput: dynamodb

- Authenticated client direct-to-storage
  - decouples high-bandwidth file transfers [images, attachments] from business logic and metadata storage
