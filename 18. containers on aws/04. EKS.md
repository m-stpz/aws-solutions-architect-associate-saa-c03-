# EKS - Elastic Kubernetes Overview

- AWS's managed service that runs K8 without requiring you to manually install, config, or maintain k8 control pane
- Kubernetes:
  - open-source container, usually docker, orchestration
  - helps with automatic deployment, scaling, and management of containers
  - cloud-agnostic
- Alternative to ECS, similar, but with different API
- Use case: company already using K8 on-prem or in another cloud and wants to migrate to AWS using K8
