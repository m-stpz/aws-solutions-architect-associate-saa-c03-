# Quiz - Containers on AWS

1. You have multiple Docker-based applications hosted on-premises that you want to migrate to AWS. You don't want to provision or manage any infrastructure; you just want to run your containers on AWS. Which AWS service should you choose?

- AWS Fargate on AWS
  - Allow you to run containers on AWS without managing the servers
  - Just a note:
    - Fargete carries a 20% to 50% premium over equivalent on-demand ec2 instances
    - however, if the bill will be higher or lower on Fargate depends on utilization curve
    - Raw prices, however, tell only half of the story, while EC2 charges for the entiry VM, fargate charges for the container resource request
      - there's no wasted compute with fargate

> Rule of thumb: start on Fargate by default for simplicity and zero maintenance. If the bill gets too large to justify engineering time, then you switch to ECS on EC2

2. Amazon Elastic Container Service (ECS) has two Launch Types: .................. and ..................

- EC2 Launch type / Fargate

3. You have an application hosted on an ECS Cluster (EC2 Launch Type) where you want your ECS tasks to upload files to an S3 bucket. Which IAM Role for your ECS Tasks should you modify?

- Wrong:
  - EC2 Instance profile
    - EC2 Instance profile is the IAM role used by the ECS agent on the ECS instance to execute ECS-specific actions
      [ex: pulling docker images from ECR and storing the container logs into CloudWatch logs]

- Correct:
  - EC2 Task role
    - IAM role used by the ECS task itself
    - Use when your container wants to call other AWS services like S3, SQS, etc

4. You're planning to migrate a WordPress website running on Docker containers from on-premises to AWS. You have decided to run the application in an ECS Cluster, but you want your docker containers to access the same WordPress website content such as website files, images, videos, etc. What do you recommend to achieve this?

- Mount EFS volume
  - EFS volumes can be shared by different ec2 instances and different ECS tasks
  - can be used as a persistent multi-az shared storage for your containers
