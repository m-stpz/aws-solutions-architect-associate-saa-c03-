# Basic Networking AWS

- AWS networking is built around software-defined networking model
- It mimics traditional on-prem networking, while offering massive scalability, flexibility, and automated management

## VPC - Virtual private cloud [Fence around resources / the campus]

- Logically isolated, private virtual networking
- A fence around a bunch of resources
- It separates some resources from others

### CIDR [Classless Inter-Domain Routing]

- /24: affects last octet
  - `10.0.0.1` to `10.0.0.254`
  - standard, ideal size for creating individual subnets [public or pviate] inside a VPC
- /16: affects last 2 octets
  - `10.0.0.1` to `10.0.255.254`
  - typically recommended size for the main CIDR block of an AWS VPC
- /8: affects last 3 octets
  - `10.0.0.1` to `10.255.255.2554`
  - usually used for large enterprise network or massive infra architecture

### Hands on

- VPC / Your VPCS / Create VPC
- Select IPv4 CIDR
  - 10.0.0.0/<24/16/8>

## Subnets [Segmentation of resources / the building]

- A range of IP addresses within your VPC that allows us to segment the network
- While a VPC would be a large gated campus, the subnet is the individual building or department inside the campus
- Reside within an single AZ

### Public vs. Private

- Public
  - resources here can send and receive traffic from the public internet
  - they must have public/elastic IP addresses
- Private
  - don't have a direct route to the internet
  - resources here are isolated from external traffic
  - if a resource here needs outbound internet access, it routes through a NAT [Network address translation] gateway

- To launch resources, you need a subnet

```
AWS Cloud ---------------
    VPC -----------------
    Private        Public
    Subnet         Subnet
```

### Standard Multi-AZ architecture [4 subnets]

- High availability
- 2 AZs

- AZ 1
  - public subnet:
    - internet-facing components, ex: ALB or public NAT gateway
    - 10.0.0.0/24
  - private subnet:
    - internal backend services or primary dbs
    - 10.0.1.0/24
- AZ 2
  - public subnet
    - redundant public-facing entry points
    - 10.0.2.0/24
  - private subnet
    - hosts secondary/replica backend services or dbs
    - 10.0.3.0/24

### Hands on

- VPC / Subnets / Create subnet
- Select VPC ID
- Subnet settings
  - name
  - AZ
    - it's common for people to create 2 public and private subnets
    - 1 is in one AZ, the other in another
      - 1 private and 1 public in AZ 1
      - 1 private and 1 public in AZ 2
      - if one AZ goes down, you still have the other
      - high-availability principle

- Create a public subnet
  - AZ 1
  - IPv4 CIDR block
    - `10.0.0.0/24`

- Create a private subnet
  - AZ 2
  - IPv4 CIDR block
    - 10.0.1.0/24
