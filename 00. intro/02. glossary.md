# Glossary

### Compute & Networking

- **Amazon Route 53:** Scalable Domain Name System (DNS) web service and domain registrar used to route traffic to infrastructure hosted on AWS or externally.
- **Amazon EC2 (Elastic Compute Cloud):** On-demand virtual servers (instances) offering resizable compute capacity in the cloud.
- **Placement Groups:** Configurations for EC2 physical instance placement—Cluster (low latency), Spread (rack fault isolation), or Partition (large-scale fault isolation).
- **Amazon VPC (Virtual Private Cloud):** Isolated virtual network environment where you define IP address ranges, subnets, route tables, and network gateways.
- **Subnet:** A logical segment of a VPC's IP address range, categorized as Public (connected to an Internet Gateway) or Private (isolated from direct internet access).
- **Internet Gateway (IGW):** A VPC component enabling communication between resources in public subnets and the internet.
- **NAT Gateway:** A managed service in a public subnet allowing private subnet instances to initiate outbound connections (e.g., for updates) while blocking inbound connections.
- **Route Table:** A set of rules (routes) used to determine where network traffic from a subnet or gateway is directed.
- **Security Group:** A stateful virtual firewall applied at the instance or network interface (ENI) level to control inbound and outbound traffic.
- **Network Access Control List (NACL):** A stateless firewall operating at the subnet level to filter traffic entering and leaving an entire subnet.
- **Elastic Network Interface (ENI):** A virtual network card in a VPC attached to an EC2 instance, containing private/public IP addresses, MAC address, and security group assignments.
- **Elastic Network Adapter (ENA):** High-performance network interface for EC2 instances offering up to 100 Gbps network throughput.
- **Elastic Fabric Adapter (EFA):** Specialized network interface engineered for High-Performance Computing (HPC) and deep learning with OS-bypass capabilities.
- **VPC Peering:** A networking connection between two VPCs enabling direct traffic routing using private IP addresses.
- **AWS Transit Gateway:** A central hub that connects multiple VPCs, on-premises networks, and VPN connections in a star topology.

### Storage & Databases

- **Amazon S3 (Simple Storage Service):** Scalable object storage service for storing and retrieving unstructured data via HTTP endpoints.
- **Amazon EBS (Elastic Block Store):** Persistent block storage volumes designed for use with EC2 instances (functions like virtual hard drives).
- **Amazon EFS (Elastic File System):** Scalable, fully managed Network File System (NFS) for Linux-based workloads accessible concurrently by multiple EC2 instances.
- **Amazon RDS (Relational Database Service):** Managed relational database engine supporting PostgreSQL, MySQL, MariaDB, Oracle, SQL Server, and Amazon Aurora.
- **Amazon DynamoDB:** Fully managed, serverless NoSQL key-value and document database offering single-digit millisecond performance at scale.

### Security, Monitoring & Scaling

- **AWS IAM (Identity and Access Management):** Security service for managing authentication (users, roles, groups) and access permissions (policies) across AWS resources.
- **AWS KMS (Key Management Service):** Managed service for creating, controlling, and applying cryptographic keys to encrypt data across AWS services.
- **AWS CloudWatch:** Monitoring and observability service for tracking metrics, collecting logs, routing events, and setting operational alarms.
- **AWS CloudTrail:** Audit service that logs API calls and user activity across your AWS account for compliance and security auditing.
- **AWS Auto Scaling:** Automated capacity management that adjusts the number of EC2 instances or resources based on demand and health metrics.
- **Elastic Load Balancing (ELB):** Service that automatically distributes incoming traffic across multiple targets (EC2, containers, IP addresses) via ALB, NLB, or GWLB.
