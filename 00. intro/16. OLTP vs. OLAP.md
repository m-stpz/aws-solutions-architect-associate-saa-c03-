# OLTP vs. OLAP

## OLTP - Online Transaction Processing

- Systems designed to handle day-to-day operations and live transactions
- Processes thousands of fast, small, real-time requests
  - ex: inserting a row; updating a record
- Focuses on speed, accuracy, and keeping data strictly consistent
- Example: Aurora, RDS, DynamoDB

## OLAP - Online Analytical Processing

- Systems designed for analytics, business intelligence, and complex reporting
- Instead of looking at one customer's orders, it scans millions of rows at once to calculate trends, sums, and averages
- Example: Redshift, Athena, S3 [when used as a data lake]

## To sum up

| Feature      | OLTP                                | OLAP                                                         |
| ------------ | ----------------------------------- | ------------------------------------------------------------ |
| Primary goal | run day-to-day business operations  | analyze data and find business insights                      |
| Query type   | simple reads and writes             | complex aggregations and scans across millions of rows       |
| Data scope   | current, active, real-time data     | historical data accumulated over years                       |
| Users        | end-users, customers, mobile apps   | data analysts, data scientists, executives                   |
| Speed prio   | instant single-row response [<10ms] | bulk processing speed for large reports [seconds to minutes] |
