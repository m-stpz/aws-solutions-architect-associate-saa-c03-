# S3 Services

## 1. Analytics, querying and ETL processing over s3

- AWS Glue: ETL [extract, transform, load] -> useful for prepare/transform data for analytics
  - glue clawlers infer schemas to populate the glue data catalog
  - serverless ETL jobs run Apache Spark or Python transformations on s3 data
  - no managing clusters
- Athena: analyze data stored in s3
  - serverless interactive SQL query services
  - analyses semi/un/structured files [CSV, JSON, Parquet, ORC] directly in s3 using standard SQL [charged per TB scanned]
- EMR [ElasticMapReduce]: big data
  - managed bug-data cluster framework [Spark, Hadoop, Hive, Presto]
  - for heavy, distributed parallel processing and custom cluster tuning over massive s3 datasets
- Redshift spectrum
  - enables existing Redshift cluster to query exabytes of external data directly in s3
  - no loading the data into redshift's local storage
- Quicksight [Amazon Quick]: BI/dashboards
  - serverless BI service that connects directly to s3 [or via athena]
  - build interactive dashboards and visualizations
- S3 tables and metadata:
  - managed apache iceberg tabular storage [s3 tables] for high-performance analytics in s3

## 2. Security, data discovery and governance

- Macie: ML for private services on s3
  - fully managed data privacy service that uses ML and pattern matching
  - discover, classify, report PII [names, credit cards, etc] and sensitive data
- Lake formation: data lake governance and access
  - centralizes data lake governance and fine-grained security [row-level, column, level, and cell-level access controls] on s3-backed data lakes
- GuardDuty: monitoring s3 data for security branch
  - monitors CloudTrail s3 data to detect anomalous access, compromised credentials, or suspicious API calls
- Object Lambda: filter s3 object before returning to caller
  - intercepts GET requests and executes custom AWS lambda code
  - dynamically transform/redact/mask PII, resize S3 objects on the fly before returning them to caller
- S3 access points and multi-region access points
  - access points: simplifies permissions on a shared bucket
  - multi-region access points: single global endpoint that routes requests to closest bucket
- S3 object lock and s3 versioning
  - object lock: enforces WORM immutability
    - compliance mode: prvents even the root user from deleting objects
    - legal hold: preserves objects indefinitely during litigation
  - s3 versioning: preserves historical object versions

## 3. Storage analytics, batch operations, and cost optimization

- S3 Storage lens: analytics dashboard
  - organization-wide analytics dashboard
  - recommendations across all s3 buckets and AWS accounts
  - storage lens vs quicksight?
    - both provide dashboard
    - quicksight: general BI for business data [sales, user behavior, application logs]
    - s3 storage lesn: storage analytics
- S3 Storage class analysis: tracks object access to transition them to IA tiers
  - tracks object access over time to recommend when to transition data to IA [infrequent access] tiers
- S3 inventory: audit reports on bucket
  - generates scheduled CSV or Parquet audit reports
  - lists all objects in a bucket along with their metadata
    - encryption status, storage class, replication status
- S3 batch operations:
  - large scale automated actions across billions of objects in a single job
    - copying, updating tags/encryption, restoring from glacier, invoking lambda function per object, running s3 batch replications
- S3 lifecycle rules: policies to transition storage class
  - automated policies that transition object versions across storage classes
    - Intelligent-tiering, standard-IA, one zone-IA, Glacier instance/flexible/deep archive
  - expire/delete objects after a given time

## 4. Event-driven compute, AI and streaming ingestion

- Lambda [via s3 event notifications or event bridge]: custom code triggered on s3 events
  - triggers serverless functions automatically on s3 object events
    - create, remove, etc
    - thumbnail generation, file parsing, fanning out via SNS and SQS
- EventBridge [s3 integration]:
  - routes s3 events up to 5 targets per rule
  - advanced content filtering
- Data firehose: real-time data -> s3
  - streaming data ingested real-time added to s3
  - can be transformed via lambda before reaching s3
- Bedrock [knowledge bases] & s3 vectors: s3 as base for RAG
  - s3 buckets as document repo for RAG
  - chunks and index s3 files into vector stores
