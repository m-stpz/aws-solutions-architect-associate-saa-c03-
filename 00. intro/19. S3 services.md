# S3 Services

## 1. Analytics, querying and ETL processing over s3

- AWS Glue
  - glue clawlers infer schemas to populate the glue data catalog
  - serverless ETL jobs run Apache Spark or Python transformations on s3 data
  - no managing clusters
- Athena
  - serverless interactive SQL query services
  - analyses semi/un/structured files [CSV, JSON, Parquet, ORC] directly in s3 using standard SQL [charged per TB scanned]
- EMR
- Redshift spectrum
- Quicksight
- S3 tables and metadata

## 2. Security, data discovery and governance

- Macie
