## AWS Global Infrastructure

- AWS Regions
- AWS Availability Zones
- AWS Data Centers
- AWS Edge Locations/Points of presence

https://aws.amazon.com/about-aws/global-infrastructure/regions_az/

- How to choose an AWS Region?
  - Compliance: data governance and legal requirements
  - Proximity to customers: reduced latency
  - Available services within a region
  - Pricing: it varies from region to region

- AWS Availability zones
  - Each region has zones (usually 3 - min 3/max 6)
  - Each availability zone (AZ) is one or more discrete data centers with redundant power, networking, and connectivity
  - Each zone is separate from each other, so they're separated from disasters
  - They're connected with high bandwidth, ultra-low latency networking

- AWS Points of presence (Edge locations)
  - 400+ points of present (400+ edge locations & 10+ regional caches)
  - 90+ cities across 40+ countries
  - Content is delivered to users with lower latency

- AWS has global services
  - Identity and Acess Management (IAM)
  - Route 53 (DNS service)
  - CloudFront (CDN)
  - WAT (Web application firewall)

- Most AWS services are region-scoped:
  - Amazon EC2 (Infrastructure as a service)
  - Elastic Beanstalk (Platform as a service)
  - Lambda (Function as a service)
  - Rekognition (Software as a service)

## Understanding Solution Architect Role

- Solution architect = business problems + technology solutions
- High-level system design, alignment meetings, and technical decision-making

1. Translating business needs into technical designs

- Business requirements: "We need customers to be able to check out in less than 3 seconds, even during peak Black Friday traffic"
- Architect's solution: Designing a highly scalable, event-driven checkout pipeline using message queues, distributed caching, and auto-scaling cloud compute instances

2. Making the "hard" technology decisions

- Which tools to use and how data flows between them
- Define:
  - the stack
  - hosting strategy
  - integration patterns

3. Managing "non-functional requirements"
