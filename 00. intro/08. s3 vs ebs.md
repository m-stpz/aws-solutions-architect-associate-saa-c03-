# S3 vs EBS

- S3 is a serverless object storage service accessible over internet via HTTP APIs
- EBS is a network-attached block storage designed to function like a physical HD mounted on an EC2 instance
  - When selecting an EC2 instance, we select the RAM
  - We'd need an EBS to have persistent volumes
  - Instance store - they are physically tied to the EC2 instance
    - If the instance goes down, data is lost
