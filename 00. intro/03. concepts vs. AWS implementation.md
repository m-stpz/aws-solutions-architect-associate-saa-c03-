# Software engineering concepts vs. AWS implementations

4. Databases and caching
5. Messaging and integration
6. Security and observability

## 1. Compute and infrastructure

| Concept                     | AWS implementation              | Definition                                                                                                  |
| --------------------------- | ------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Virtual machine (VM)        | EC2 (Elastic Compute Cloud)     | A virtualized server running an OS on shared/dedicated physical hardware                                    |
| Containers as a service     | ECS or EKS                      | Infra to run docker containers. EC2 is AWS's proprietary orchestrator. EKS is managed by Kubernetes         |
| Serverless functions        | AWS Lambda                      | Event-driven code execution (FaaS). Code that spins on micro-containers on demand to execute it             |
| Virtual network card (vNIC) | ENI (Elastic Network Interface) | Software-defined interface for holding IP/MAC addreses, and security groups that plugs into an EC2 instance |

## 2. Networking and traffic routing

| Concept                        | AWS implementation | Definition                                                                                                                 |
| ------------------------------ | ------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| Domain Name System (DNS)       | Route 53           | Global DNS service that translates domain names to IP addresses and routes traffic                                         |
| Content delivery network (CDN) | CloudFront         | Global caching network (edge locations) that caches static assets (images, HTML, videos) closer to users to reduce latency |
| Load balancer                  | ELB (ALB / NLB)    | Reverse proxy that distributes incoming HTTP/TCP traffic across multiple backend services/containers                       |
| Reverse proxy / API gateway    | Amazon API Gateway | Entry point for your APIs that handles HTTP routing, rate-limiting, authentication, and request transformation             |

## 3. Storage

| Concept                            | AWS implementation          | Definition                                                                                                              |
| ---------------------------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Virtual hard drive (block storage) | EBS (Elastic Block Store)   | Raw block storage attached to a single EC2 instance (like an SSD/HDD plugged via SATA)                                  |
| Object store (HTTP blob store)     | S3 (Simple Storage Service) | Key-value store for files (photos, backups, logs). Files are accessed via HTTP API calls, not OS file path system paths |
| Network attached storage (NAS)     | EFS (Elastic File System)   | Managed NFS drive that can be mounted by hundreds of servers simultaneously to read/write shared files                  |

## 4. Databases and caching

| Concept                 | AWS implementation | Definition                                                                                                                  |
| ----------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| Managed relational db   | RDS                | Automated management layer around SQL engines (PostgreSQL, MySQL). AWS handles OS patching, automated backups, and failover |
| Document / key-value db | DynamoDB           | Fully managed, auto-scaling NoSQL db designed for high-throughput, low-latency workloads (similar to Cassandra or MongoDB)  |
| In-memory cache         | ElastiCache        | Fully managed Redis or Memcached instances used to cache db queries or manage user sessions states in memory                |
| Data warehouse          | Redshift           | Columnar db optimized for running analytical OLAP queries over massive datasets (terabytes to petabytes)                    |
