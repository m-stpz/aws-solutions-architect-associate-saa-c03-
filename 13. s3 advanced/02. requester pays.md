# Requester pays

- In general, bucket owners pay for all s3 storage and data transfer associated with their bucket

| type           | responsible for cost storage | responsible for cost networking |
| -------------- | ---------------------------- | ------------------------------- |
| standard       | owner                        | owner                           |
| requester pays | owner                        | requester                       |

- `With requester pays buckets`, the requester pays the cost of the request and the data download from the bucket
  - instead of the bucket owner
  - helpful when you want to share large datasets with other accounts

> Requester must be authenticated in aWS [can't be anonymous]
