# IAM Conditions

- optional block inside an IAM policy statement
- lets you specify the exact circumstances a policy statement takes effect

```json
"Condition": {
    "ConditionOperator": {
        "ConditionKey": "ConditionValue"
    }
}
```

- Allowing s3 reads only over HTTPS [TLS] from a specific corporate CIDR range:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::confidential-docs/*",
      "Condition": {
        "Bool": {
          "aws:SecureTransport": "true"
        },
        "IpAddress": {
          "aws:SourceIp": "203.0.113.0/24"
        }
      }
    }
  ]
}
```
