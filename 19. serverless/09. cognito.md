# Cognito

- AWS IAM service for customer-facing web and mobile
- Cognito is split into two sub-services
  - user pools
  - identity pools

```
┌────────────────────────────────────────┐
│          Amazon Cognito                │
├────────────────────┬───────────────────┤
│    User Pools      │  Identity Pools   │
│  (Authentication)  │  (Authorization)  │
│        Who         │       What        │
│    are you?        │   can you access? │
└─────────┬──────────┴─────────┬─────────┘
          │                    │
          ▼                    ▼
     JSON Web Tokens     Temporary AWS IAM
    (ID / Access /       Credentials (STS)
      Refresh)           to hit S3, DynamoDB
```

| Dimension        | Cognito User Pools [CUP]                   | Cognito Identity Pools [CIP]                |
| ---------------- | ------------------------------------------ | ------------------------------------------- |
| Goal             | Authentication                             | Authorization to AWS                        |
| Output           | OIDC JWT tokens [id, acess, refresh]       | temp AWS IAM cred                           |
| target consumer  | application abd backend APIs [API gateway] | direct AWS service APIs [s3, dynamodb, IoT] |
| identity storage | yes: maintains user accounts and profiles  | no, only exchange broker                    |

## User pools: authentication and identity directory

- sign in functionality for app users
- integrate with API gateway and ALB
- user db
  - serverless db of user for web and mobile apps
- handles: sign-up, sign-in, account recovery, password policies, and multi-factor auth [MFA]
  - email and phone number verfication

```
    authenticate/retrieve token
client ---------> Cognito User Pools
    |                   ^ evaluate cognito token
    |-----------> API gateway -----> backend
    Rest API +
    pass token
```

## Identity pools [federated identities]: AWS resource authorization

- purpose is to allow users to have a temp AWS IAM credential to interact with AWS resources
- auth to aws
- temp AWS IAM cred

```
                        login and get token [authentication]
web and mobile applications <--------------> Cognito user pools
    |    |                                               |
    |    |--------------> cognito identity pools ---- validate
    |    exchange token for temp
    |    AWS cred
    |
    direct access to AWS
    - private s3 bucket
    - dynamodb table
```
