# DynamoDB

- AWS proprietary technology
- managed serverless nosql db, ms latency
  - highly available
  - multi AZ by default
  - read and writes are decoupled
  - transaction capability
- capacity modes:
  - provisioned capacity with optional auto-scaling
  - on-demand capacity
- can replace Elasticache as a key/value store
  - storing session data for example, using TTL feature
- DAX [dynamodb acceleator] for read cache, ms read latency
- Security, authentication and authorization is done through IAM
- Event processing: dynamodb streams to integrate with AWS lambda or Kinesis data streams
- Automated backups up to 35 days with PITR [restore to new table], or on-demand backups
- Export to s3 without using RCU within the PITR window, import from s3 without using WCU
- Great to rapidly evolving schemas

- Use case: serverless applications development, small docs 100s kb
  - distributed serverless cache
