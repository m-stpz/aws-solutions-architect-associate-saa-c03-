# ElastiCache

- Managed redis/memcached
- in-memory data store, sub-ms latency
- select an ElastiCache instance type
- support for clustering [Redis] and multi az, read replicas [sharding]
- Security through IAM, security groups, KMS, redis auth
- backup/snapshot/point in time restore feature
- managed and scheduled maintenance

> Important!: requires some application code changes

- Use case:
  - key/value store
  - frequent reads, less writes
  - cache results for DB queries
  - store session data for websites
  - can't use SQL
