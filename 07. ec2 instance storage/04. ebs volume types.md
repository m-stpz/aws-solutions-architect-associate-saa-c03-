# EBS Volumes

- 6 types

1. gp2/gp3 (SSD): general purpose SSD
   - balances price/performance
   - wide variety of workloads
2. io1/io2 block express (SSD): highest-performance SSD volume
   - mission-critical, low-latency or high-throughput workloads
3. st1 (HDD): low cost HDD volume
   - used for frequently accessed, throughput-intensive workloads
4. sc1 (HDD): lowest cost HDD volume
   - used for less frequently accessed workloads

- EBS volumes are characterized in size / throughput / IOPS
  - only gp2/gp3 and io1/io2 can be used as boot volumes

## General purpose SSD [`gp` type]

- Cost effective storage, low-latency
- System boot volumes, virtual desktops, development and test environments
- 1gb to 16tb
- gp3: can scale IOPS and throughput independently from each other
  - baseline 3k IOPS and throughput of 125 mb/s
  - can increase IOPS to 16k and throughput up to 1kmb/s independently
- gp2: IOPS and throughput scale together
  - baseline 3k IOPS
  - size of the volume and IOPS are linked, max IOPS 16k

## Provisioned IOPS SSD

> PIOPS means: Provisioned IO Operations Per second

- In cloud storage, standard drives scale performance based on size (e.g. larger disk gives you more speed)
  - Priovisioned IOPS allows us to have a greater IOPS, independent from the storage volume
  - You can scale the speed independent from the storage

- Critical business applications with sustained IOPS performance
  - or applications that need > 16k IOPS
- Great for dbs workloads that are sensitive to storage performance and consistency
- io1: 4gb - 16tb
  - max PIOPS 64k for nitro ec2 instances & 32k for others
  - can increase PIOPS independently from storage size
- io2 block express: 4gb - 64tb
  - sub-millisecond latency
  - max PIOPS: 256k with an IOPS:GB Ratio of 1000:1
- Support EBS multi-attach

## Hard Disk Drives (HDD)

- Cannot be a boot volume
- 125gb to 16tb
- Throughput Optimized HDD (st1)
  - big data, data warehouses, log processing
  - max throughput 500mbs - max IOPS 500
- Cold HDD (sc1):
  - for data that isn't frequently accessed
  - where lowest cost is important
  - max throughput: 250mbs - max IOPS 250

| Requirement                               | choose                      | Why?                                             |
| ----------------------------------------- | --------------------------- | ------------------------------------------------ |
| Standard EC2 boot disk / general workload | `gp3`                       | Cost-effective, predictable baseline performance |
| High-performance relational db            | `io2` / `io2 block express` | Guaranteed sustained IOPS, ultra-low latency     |
| Big data / data analytics streaming       | `st1`                       | High throughput (MB/s) at low cost per GB        |
| Cheap historical log storage              | `sc1`                       | Cheapest block storage cost in AWS               |
