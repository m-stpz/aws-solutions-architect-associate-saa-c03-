# AMI (Amazon Machine Image) Overview

- AMI = Amazon Machine Image
- AMI are a customization of an EC2 instance
  - add your own software, configuration, OS, monitoring
  - faster boot / less config time because all software is pre-package
- AMI are built for a specific region (and can be copied across regions)
- You can launch EC2 instances from:
  - Public AMIs: AWS provided
  - Your own AMIs: you make and maintain them
  - An AWS marketplace AMI: an AMI someone else made (and potentially sells)

- Why to use an AMI?
  - faster initialization
  - saving specific EC2 instances config: OS, security, etc

## How to create one

1. Start an EC2 instance and customize it
   - Once the instance has been created, right click
   - Image and templates
   - Create an image
2. Stop the instance (for data integrity)
3. Build an AMI - this also creates EBS snapshots
4. Launch instances from other AMIs

us-east-1A ---> create AMI --> Launch from AMI ---> us-east-1b

### Existing AMIs can be access on:

- EC2/Instances/Images/AMIs

### Using an AMI to launch an EC2 Instace

There are two ways:

1. On images AMIs, on the specific image, click on `Launch Instance from AMI`
2. Or, go to the EC2 instance launcher, and instead of selecting `Quick Start` tab, select `My AMIs`
