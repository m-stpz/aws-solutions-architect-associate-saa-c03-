# EBS Multi-attach io1/io2 Family

- Attach the same EBS volume to multiple EC2 instances in the same AZ
  - this is only allowed on Provisioned IOPS SSD volumes

```
ec2_ins     ec2_ins2    ec2_ins3
    \           |           /
[   io2 volume with multi-attach   ] ====> IN THE SAME AZ
```

- Each instance has full read/write permissions to the high-performance volume
- Use case:
  - higher application availability
  - applications that must manage concurrent write operations
- **Up to 16 EC2 instances can connect to it** [important]
- Must use a file system that's cluster-aware (not XFS, EXT4, etc...)
