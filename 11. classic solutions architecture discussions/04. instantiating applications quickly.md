# Instantiating applications quickly

- When launching a full stack (EC2, EBS, RDS), it can take time to:
  - install applications
  - insert initial/recovery data
  - configure everything
  - launch the application

- EC2 instances:
  - golden AMI: install applications, OS dependencies, etc, beforehand and launch EC2 instance from the Golden AMI
  - Bootstrap using user data: for dynamic config and use data scripts
    - however, install applications, OS deps, etc, isn't good to do here since it's too heavy and the instances would be basically doing the same others already did
  - hybrid: golden AMI + user data [elastic beanstalk]

- RDS dbs:
  - restore from a snapshot -> db will have schemas and data ready

- EBS volumes
  - restore from a snapshot -> disk will be formatted and have the correct data
