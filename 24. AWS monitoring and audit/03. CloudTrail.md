# CloudTrail

- Provider paper trial for performed actions
- Governance, compliance and auditing for AWS account
- Enabled by default
- Get a history of events / API calls made within your AWS account through:
  - console, SDK, CLI, AWS Services
- Logs can be put from CloudTrail into CW logs or S3
- A trail can be applied to all regions [default] or single region
- If a resource is deleted in AWS, investigate CloudTrail first

```
                        inspect and audit
source ---------------> CloudTrail console ---------> CW logs
- SDK                                      |--------> S3 buckets
- CLI
- Console
- IAM Users/Roles
```

## CloudTrail events

- Management events
  - operations that are performed on resources in your AWS
  - by default, trails are configured to log management events
  - can separate read events from write events

- Data events
  - by default, data events aren't logged, because of high volume operations
  - S3 object-level activity can separate read/write
  - Lambda function execution activity

- CloudTrail insights events
  - you need to enable and pay for it
  - detect unusual activity in your account
    - innacurate resource provisioning
    - hitting service limits
    - bursts of AWS IAM actions
    - gaps in periodic maintenance activity
  - analyzes normal management events to create a baseline
    - then continuously analyzes write events to detect unusual patterns
    - anomalies appear in the CloudTrail console
    - event is sent to s3
    - EventBridge event is generated [for automation needs]

```
management events ------> CloudTrail insights --------> Insights Events ----> CloudTrail console
                                                                        |---> S3 bucket
                                                                        |---> EventBridge event
```

### CloudTrail events retention

- by default, events are stored 90 days
- to keep events beyond this period, log them to s3 and use athena

## CloudTrail and EventBridge integration

- API events can generate logs on API calls, which can be sent to EventBridge for alerts

```
     DeleteTable API call        Log API call              event               alert
User -------------------> DynamoDB ----------> CloudTrail -------> EventBridge --------> SNS
                                                [any API call]
```

- You can be notified on:
  - API calls
  - User assuming a role
  - Security group rules changes
