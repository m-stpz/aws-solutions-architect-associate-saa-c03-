# Summary Monitoring and Auditing

- CloudWatch, EventBrdige, CloudTrail and AWS config make the core for:
  - observability
    - CloudWatch: measures operational performance
  - auditing
    - CloudTrail: records API accountability
  - governance
    - AWS config: trackes resource config state and compliance
  - event-driven automation stack

- EventBridge: routes real-time events to trigger automated workflows

- For more info see 18. observability, auditing and governance

- CloudWatch: observability
  - how are my applications and infra performing right now?
  - operational observability and performance monitoring

- CloudTrail: auditing
  - who made what aPI call, when, and from where?
  - governance, security auditing and API accountability

- AWS config: governance
  - what did this resource look like at time X, and does it meet compliance rules?
  - config management, drift detection and compliance

- EventBrigde
  - when event X happens, what downstream system should react?
  - serverless event routing, pub/sub & scheduled automation
