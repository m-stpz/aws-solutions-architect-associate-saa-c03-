# AWS Snowball

- It's being discontinued, however, it might still appear on exams
  - nov. 2025: new accounts can no longer order it
  - dec. 2026: aws will officially end support

- Highly-secure, portable devices to collect and process data at the edge, and migrate data into and out of AWS
- Helps migrate petabytes of data
- You'd receive a physical device and then ship it

## Snowball edge

- Physical device provided by AWS to transporte LARGE volumes of data [TB to PB] into and out of the AWS cloud
- Used when network bandwidth is: too slow/expensive or unavailable
- Instead of uploading massive datasets over the internet, you:

1. order a physical device from AWS management console
2. load data locally
3. ship it back to AWS
4. they will upload it into S3
