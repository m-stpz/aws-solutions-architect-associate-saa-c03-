# Data Sync

- Move large amount of data to and from
  - on-premises / other cloud to AWS [NFS, SMB, HDFS, S3 API...] - needs agent
  - AWS to AWS [different storage services] - no agent needed

- Can sync to:
  - S3: any storage classes, including glacier
  - EFS
  - FSx: windows, lustre, netapp, openZFS

- Replication tasks can be scheduled hourly, daily, weekly
- **File permissions and metadata are preserved** [NFS POSIX, SMB,...]
- One agent task can use 10gbs, can setup a bandwidth limit

```
|[on-premises]                               |                  | [aws cloud/region]                          |
| NFS/SMB --------------> AWS data sync agent| -- TLS --------> | AWS Data sync    ---- [aws storage resource]| // AWS Storage resource: s3 standard, standard-IA intelligent-tiering
| server    NFS/SMB                          | <--------------- |                                             | // one zone-IA, glacier, glacier deep archive, EFS, FSX
```
