# Storage Comparison

- S3: object storage
  - flat namespace
  - 11 nines durability
  - 5tb max object size
  - object-level storage classes
- S3: object archival
- EBS volumes: network storage for once ec2 instance at a time
  - attached to one ec2 instance at a time
  - persistent
  - low-latency block volumes
- Instance storage: physical storage for your EC2 instance [high IOPS]
  - ephemeral
  - physically attached to host
  - high IOPS
  - data lost if instance stops or terminates
- EFS: network file system for linux instances, POSIX filesystem
  - POSIX-compliant
  - multi-instance shared file system for linux workloads
- FSx for windows: network file system for windows servers [SMB]
- FSx for lustre: high performance computing linux file system [HPC]
- FSx for NetApp ONTAP: high OS compatibility [entreprise compatibility]
- FSx for OpenZFS: managed ZFS file system
- Storage gateway: S3 and FSX file gateway, volume gateway [cache and stored], tape gateway
  - bridges on-prem to cloud
- Transfer family: FTP, FTPS, SFTP interface on top of amazon s3 or amazon EFS
  - fully managed FTP, FTPS, and SFTP interface backed by amazon S3 or EFS
- DataSync: schedule data sync from on-premises to AWS, or AWS to AWS
  - automated, scheduled, high-speed data transfer between on-premises storage and AWS
- Snowcone/snowball/snowmobile [deprecated]: to move large amounts of data to the cloud, physically
- Database: for specific workloads, usually with indexing and querying
