# Quiz - Route 53

1. You have purchased mycoolcompany.com on Amazon Route 53 Registrar and would like the domain to point to your Elastic Load Balancer my-elb-1234567890.us-west-2.elb.amazonaws.com. Which Route 53 Record type must you use here?

- Alias
  - why?
    - `mycoolcompany.com` -> this is the zone apex/root domain, it doesn't have prefixes like `www.` or `api.`
    - CNAME records can't be created at the zone apex/root level
    - Alias records are proprietary AWS extension designed specifically to combat this CNAME limitation
      - works at zone apex
      - behaves like an `A` record externally
      - zero query cost
    - subdomain to ELB `app.mycoolcompany.com` -> can use CNAME or Alias (alias is still best practice)
    - zone apex `mycoolcompany.com` -> must use alias

2. You have deployed a new Elastic Beanstalk environment and would like to direct 5% of your production traffic to this new environment. This allows you to monitor for CloudWatch metrics and ensuring that there're no bugs exist with your new environment. Which Route 53 Routing Policy allows you to do so?

- Weighted
  - allows us to redirect a part of traffic based on weight/percentage
  - common use case to send part of traffic to a new version of your application

3. You have updated a Route 53 Record's myapp.mydomain.com value to point to a new Elastic Load Balancer, but it looks like users are still redirected to the old ELB. What is a possible cause for this behavior?

- Because of TTL
  - Each DNS record has a TTL
  - It tells clients how long to cache the values, in order not to overload the DNS resolvers with DNS requests
  - TTL should strike a balance between how long the value should be cached, thus possibly stale, vs. how many requests should go through the DNS resolver

4. You have an application that's hosted in two different AWS Regions us-west-1 and eu-west-2. You want your users to get the best possible user experience by minimizing the response time from application servers to your users. Which Route 53 Routing Policy should you choose?

- Latency
  - evalutes the latency between users and aWS regions and help them get a DNS response that minimizes response time

5. You have a legal requirement that people in any country but France should NOT be able to access your website. Which Route 53 Routing Policy helps you in achieving this?

- Geolocation
  - because through geolocation we can attend to political/compliance reasons
  - location-based compliance

6. You have purchased a domain on GoDaddy and would like to use Route 53 as the DNS Service Provider. What should you do to make this work?

- Create a public hosted zone (aws) and update the 3rd party (ex: GoDaddy) registrar NS records
  - public hosted zones -> used for people requesting your website through the internet

7. Which of the following are NOT valid Route 53 Health Checks?

- Health checks that monitor SQS queue
