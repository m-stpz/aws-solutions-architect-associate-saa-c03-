# DNS

- Domain Name System
- Translates human-readable hostnames into machine IP addresses
- Like a phone book which connects the person's name with his/her phone
- DNS is the backbone of the internet

## Terminology

- Domain Registrar: Route 53, GoDaddy, ...
- DNS records: A, AAAA, CNAME, NS, ...
  - individual config instructions stored in a db that tells DNS clients how to handle traffic for a specific name
  - `A` record: maps a hostname to ipv4
  - `AAAA` record: maps a hostname to ipv6
  - `CNAME` (canonical name): maps one hostname (alias) to another (ex: app.example.com -> lb.aws.com)
  - `NS` (name server): specifies which servers have authoritative DNS records for that domain
- Zone file: contains DNS records
- Name server: resolves DNS queries (authoritative or non-authoritative)
- Top level domain (TLD): .com, .us, .io, .gov, .org, ...
- Second level domain (SLD): amazon.com, google.com
- URL: uniform resource locator
- FQDN (fully qualified domain name)
