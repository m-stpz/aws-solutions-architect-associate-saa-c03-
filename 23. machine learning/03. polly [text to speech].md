# Polly

- Transform text into speech
- Turn text into likelike speech using deep learning
- Allow us to create applications that talk

## Lexicon & SSML

- customize the pronunciation of words with lexicon
  - stylized words
  - acronyms
- upload the lexicons and use them in the SynthesizeSpeech operation

- generate speech from plain text or from documents marked up with speech synthesis markup language [SSML]
  - enables customization
    - emphasizing specific words/phrases
    - using phonetic pronunciation
    - including breathing sounds, whispering
    - using the newscaster speaking style
