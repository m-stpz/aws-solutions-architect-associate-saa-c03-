# Textract

- Extracts text, handwriting, and data from any scanned documents

```
  analyze       result
doc ---> textract ---> {"..."}
```

- Extract data from forms and tables
- Read and process any type of document [PDFs, images, ...]
- Use cases
  - financial services, ex: invoices, financial reports
  - healthcare, ex: medical records, insurance claims
  - public sector, ex: tax forms, ID docs, passports
