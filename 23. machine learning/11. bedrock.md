# Bedrock

- fully managed, serverless platform designed to use generative AI
- gives us a unified API to access leading foundation models
- also managed primitives for enterprise RAG, agentic workflows and safety

## Core architecture

- with bedrock, we interact with one unified endpoint
- switch models by altering a single parameter in the code rather than rewriting the integration

## Builder capabilities

- Bedrock knowledge base [managed serverless RAG]
- Bedrock agents
- Bedrock guardrails

## Bedrock vs. SageMaker

| Dimension        | Bedrock                                                                               | SageMaker                                                       |
| ---------------- | ------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| primary use case | consuming foundation models via managed APIs & building genai apps                    | end-to-end ML training, data science, custom model architecture |
| infra            | 100% serverless; no EC2/GPU instances to manage                                       | managed clusters, spot/on-demand GPU instances, endpoints       |
| pricing model    | pay-as-you-go per token, or provisioned throughput for dedicated capacity             | compute instance hours [$/hour for traning jobs and endpoints]  |
| custom models    | fine-tuning supported base models or importing custom weights via custom model import | complete freedom to train any neural network from scratch       |

## Billing

- On-demand: pay per input/ouput token
  - idle cost is 0
- Provisioned throughput [PT]: commit to model units for 1-6 months
  - guarantees low-latency, fixed throughput capacity without hitting shared rate limits
  - used normally by high-volume enterprise systems
- Batch mode: submit bulk async inference requests at ~50% discount compared to on-demand pricing
