# AWS CLI

- 3 options to access AWS:

1. AWS Management Console: the web platform [protected by password + MFA]
2. AWS CLI: [protected by access keys]
3. AWS SDK: [protected by access keys]

- Access keys are generated through AWS console

## Installing AWS on Mac

https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html

```bash
# to test
which aws
aws --version
```

## How to create access keys

1. IAM / IAM Users / Select user
2. Create Access key
3. Save the values you see: access key + secret access key. You will need it.
4. On the terminal

```bash
# setup credentials
aws configure

# verify
aws iam list-users
```

## Using CloudShell

On the top menu, there's a shell icon. Click on it, a terminal will appear.

- A terminal in the cloud of AWS
- You can create files on it. These files remain saved there

```bash
echo "test" > demo.txt
cat demo.txt
# test
```

- You can upload/download files
