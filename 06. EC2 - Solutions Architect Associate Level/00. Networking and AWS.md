# Networking and AWS

Six core layers:

- boundary definition
- traffic routine
- security
- edge delivery
- hybrid connectivity
- service-to-service access

## Virtual Private Cloud (VPC) & IP Addressing

- VPC is the logically isolated slice of AWS cloud
- CIDR Blocks: continues range of IP addresses for your VPC using CIDR notation
- Subnets: CIDR blocks are carved up into smaller subnets
  - the subnet is bound to a single AZ (availability zone)
  - public subnet: has a direct route to an Internet Gateway (IGW)
    - resources get public IP
  - private subnet: no direct internet route
    - standar practice for dbs, applications backends, and internal APIs

## Gateways and routing

- Traffic only moves where your route tables allow it to go
- Internet gateway (IGW): allows instances in public subnets to communicate bi-directionally with the internet
- NAT Gateway (Network address translation): placed in a public subnet to allow resources in a private subnet to reach out to the internet while blocking inbound traffic from initiating connections to them
- Route tables: explicity destination-to-target mapping to subnets
  - `Destination: 0.0.0/0 -> Target: igw-xxxxx`
