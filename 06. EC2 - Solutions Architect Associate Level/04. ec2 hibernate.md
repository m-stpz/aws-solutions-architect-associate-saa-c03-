# EC2 Hibernate

- We can stop or terminate instances
  - Stop: the data on disk (EBS - Elastic block store) is kept, like SSD
  - Terminate: any volumes that were set to be destroyed when the instance is terminated will be removed

- On start,
  - First start: OS boots and the EC2 user data script runs
  - OS boots up
  - Application starts, caches get warmed up and this takes time

- EC2 Hibernate:
  - In-memory (RAM) is preserved
    - The RAM is dumped into EBS and loaded on boot
  - Instance boot is faster (OS isn't stopped)
  - Use cases:
    - long-running processing
    - saving the RAM in
  - Instance shouldn't be hibernated for > 60 days

- When creating an EC2 instance, you should enable the hibernate behavior
  - the root EBS volume needs to be encrypted
  - the EBS of the instance must have enough space to add the RAM there
    - EBS size needs to be > instance memory
