# Elastic Network Interfaces (ENI)

- Logical component in a VPC that represents a virtual network card
- The ENI can have the following attributes:
  - Primary private IPv4, one or more secondary IPv4
  - one elastic IP per private IPv4
  - one or more security groups
  - a MAC address
- It handles network traffic for resources connected to your VPC
  - acts as a bridge between EC2 instaces (or managed AWS services) and the underlying network

> Amazon VPC (Virtual Private Cloud): Isolated virtual network environment where you define IP address ranges, subnets, route tables, and network gateways.

## Important terminology to understand this concept

1. Virtual network card (the concept)
2. ENI - Elastic network interface (AWS implementation)

### 1. Virtual network card (general concept)

it's similar to a physical network card on the computer (ethernet port)

- this card has a port where we plug a network cable
- this card has a unique id (MAC address) and allows the computer to get an IP, so it can talk to the internet and other devices
- the virtual network card is the same, but it's code, not a piece of metal
- this is the "code" version for the EC2 instance
- to the OS inside the machine, it operates just like a real, physical network card
- machine <--> virtual network card <--> network

### 2. Elastic network interface

- A virtual network card that you plug into a cloud server

## Why use an ENI (Elastic Network Interface)?

They basically decouple network identify from compute hardware

- the server is just a temporary CPU/RAM engine, the persistent network identity is the ENI

1. Zero-downtime failover: a network interface that can be moved from node 1 to node, without other nodes being aware of this change

- if a server A suffers from a hardware crash, without an ENI, you'd have to spin up Server B, get a new IP addres and update config files, environment variables, or DNS records
- with an ENI, the IP address lives inside the ENI, not the server. This way we simple detache the ENI from the crashes server A and attach it to server B. Server B instantly becomes workable and the system keeping running without realizing the server hardware changed

2. Network isolation: sometimes a single server needs to exist on two different networks at the same time. You can plug two ENIs into one EC2 instance:

- primary ENI (`eth0`): connected to a publish subnet to serve web traffic to users on the internet
- secondary ENI (`eh1`): connected an isolated private/management subnet for internal SSH access, db queries, or server backups
