# Quiz EC2 Fundamentals

1. Which EC2 purchasing options can provide you with the biggest discount, but it's not suitable for critical jobs or dbs?

- Spot instances
  - good for short workloads
  - cheapest ec2 purchasing option
  - less reliable because we can lose the instance

2. What should you use to control traffic in and out of EC2 instances?

- Security groups
  - they operate at the EC2 instance level
  - control traffic

3. Which E2C purchasing options should you use for an application you plan to run on a server continuously for 1 year?

- Reserved instances

4. You are preparing to launch an application that will be hosted on a set of EC2 instances. This application needs some software installation and some OS packages need to be updated during the first launch. What is the best way to achieve this when you launch the EC2 instances?

- Write a bash script that installs what you want, then use this script in the EC2 user data when you launch EC2 instances

5. Security groups can be attached to only one EC2 instance?

- False: they can be attached to multiple EC2 instances within the same AWS region/VPC

6. You would like to deploy a database technology on an EC2 instance and the vendor license bills you based on the physical cores and underlying network socket visibility. Which EC2 Purchasing Option allows you to get visibility into them?

- Dedicated hosts: gives you visibility into the underlying hardware configutation
  - dedicated hosts are important for deploying licensing-sensitive software
