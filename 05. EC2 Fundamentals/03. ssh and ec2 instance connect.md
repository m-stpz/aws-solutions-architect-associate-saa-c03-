# SSH

- SSH can be used on Mac, Linux, and windows >= 10
  - for windowns < 10, use `putty`
- There's also EC2 instance connect

## What is SSH?

- Secure Shell is a network protocol
- It allows you to securely access and control a remote computer/server over an untrusted network
- When we SSH into a machine, it opens a secure, encrypted CLI session
- It's like you're typing in the terminal of that machine

### Common uses

1. Remote server management: log into servers to run commands, install softwares, check logs, or restart services
2. Key-based authentication (SSH keys): instead of typing passwords, SSH commonly uses cryptographic key pairs
   - allows passwordless, highly secure logins
3. Secure file transfer (SFTP & SCP): SSH provides underlying encryption for protocols used to transfer files securely between machines

## How SSH Linux/Mac

- SSH allows us to control a remote machine, all using the command line

To SSH:

1. grab your `.pem` permission
2. identify the `ipv4` of your instance
3. check it out if the security groups allow the connection of SSH
4. check your IP on mac `ipconfig getifaddr en0`
5. close the permissions

```bash
chmod 0400 <pem-file>
```

6. run the command

```bash
ssh -i <pem-file> ec2-user@<instance-public-ip>
# pem file must be on the same directory
```

Now, the commands we run are running from within our ec2 instance

6. to logout: `CTRL + D` or `logout` on the terminal
