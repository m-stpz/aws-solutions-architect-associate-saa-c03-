# EC2 Instance Purchasing options

- On-demand instances: short workload, predictable pricing, pay by second
- Reserved: 1 and 3 yeras
- Saving plans
- Spot instances
- Dedicated host
- Dedicated instances
- Capacity reservations

## EC2 On Demand

- Pay for what you use
  - linux/windows: billing per second, after the first minute
  - all other os: per hour
- Highest cost, but no upfront payment
- No long-term commitmment
- Better for **short-term** and **un-interrupted workloads**, where you can't predict how the application will behave

## EC2 Reserve instances

- Good for steady-state usage applications
- Up to 72% discount compared to on-demand
- Reserve a specific instance attributes (instance type, region, tenancy, os)
- Reserve it for a period: 1 year (+discount) or 3 years (+++discount)
- Payment options: no/partial/all upfront

## EC2 Savings PLans

- Get a discount on long-term usage
- Commit to a certain type of usage ($10/h for 1/3 years)
- Usage beyond this is billed at on-demand price

## EC2 Spot instances

- Can get a discount of up to 90% to on-demand
- However, you can "lose" them at any point in time, if your max price is less than the current spot price
  - it's like audictioning for ec2 instances
- The most cost-efficient instances in AWS
- Useful for workloads that are resilient to failure
  - batch jobs
  - data analysis
  - image processing
  - any distributed workloads
  - workloads with a flexible start/end time

- Not suitable for critical jobs or dbs

## EC2 Dedicated host

- A physical server with EC2 instance capacity fully dedicated to your use
- Good for compliance requirements and usage of your existing server-bound software licenses
- Purchasing options: on-demand and reserved
- The most expensive option
- Useful for:
  - softwares with complicated licensing model
  - companies with strong regulatory/compliance needs
