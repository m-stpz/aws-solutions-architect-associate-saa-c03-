# EC2 Instance Roles

- SSH connect to your instance [see how to do it on the 03.ssh...md file]

```bash
aws --version # to check the cli version installed
aws iam list-users # it will fail if it doesn't have the correct IAM role attached to the EC2 instance
```

> Never enter your Access Key ID and the Secret Access Key into an EC2 Instance. Instead, use IAM Rules

- To attach a security role, you can:

1. Verify the roles available on IAM/Roles/<RoleName>
2. Attach it to the instance
   - EC2/Instances/Click the instance
   - Actions dropdown/Security/Modify IAM role
   - Then, select the given role

3. Now, on the SSH terminal, which is connected to the EC2 instance that we've just added the IAM role, you should run

```bash
aws iam list-users
```
