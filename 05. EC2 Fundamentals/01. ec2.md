# EC2

## EC2 Basics

- EC2 one of the most popular AWS services
- EC2 = Elastic Compute Cloud. It's IaaS [Infrastructure as a service]
- Consists of:
  - renting virtual machines (EC2)
  - storing data on virtual drives (EBS)
  - distributing load across machines (ELB)
  - scaling the services using an auto-scaling group (ASG)

- It's a VM in AWS's data centers, rather than a container

## EC2 (VM) vs. Container

- EC2 (Virtual machine): virtualizes at the **hardware level**
  - A hypervisor slices up a physical CPU and RAM into separate, fully isolated environments
  - Each EC2 instance runs its own guest OS with its own kernel
- Container: virtualizes at the **os level**
  - Containers sit on top of a host OS and share the same OS kernel
  - Meaning, it only packs your code, runtime, and deps into lightweight processes

## EC2 Concepts

- It's like a blank computer

### Building blocks

There are 4 core components

1. AMI (Amazon Machine Image): Operating system and apps
   - blueprint for the virtual machine
   - containers the OS, pre-installed software and config files
2. Instance type (CPU & memory hardware profile)
   - t, c, m, r: instance focus
     - t / m: general purpose (balanced web apps, microservices)
     - c = compute optimized (high CPU loads, batch processing)
     - r = memory optimized (in-memory caches like Redis, heavy dbs)
     - g = AWS graviton (ARM-based chips, often cheaper/faster)
   - size: micro, medium, xlarge
3. EBS Volume (Virtual hard drive) - EBS = Elastic Block Store
   - persistent virtual hard drive attached to the instance
   - if the EC2 instance crashes/reboots, the EBS volume remains intact
4. Security group (virtual firewall)
   - EC2 instance defaults to being "closed" to outside world
   - security group: evaluates rules
   - controls inbound/outbound traffic
   - explicitly open ports

## EC2 Config

- You can select:
  - the OS: linux (most popular), windows, or macos
  - the compute power (CPU)
  - the memory (RAM)
  - the storage
    - network-attached (EBS & EFS)
    - hardware (EC2 instance store)
  - network card: speed of the card, Public IP address
  - firewall rules: security group
  - bootstrap script (configure at first launch): EC2 user data

### EC2 user data

> Bootstrap: to advance oneself using only existing, internal resources without external help

- We can bootstrap our instances using an EC2 user data script
  - Bootstrapping = launching commands when it starts
  - the command runs once when the instance starts
- EC2 user data can be used to:
  - install updates/software
  - download common files
  - some setup/config
- It runs with the root user
